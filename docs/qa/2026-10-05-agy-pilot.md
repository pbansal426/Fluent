## Top 5 Things That Would Stop a Grandma

1. **Input and Microphone Controls are Completely Hidden on Initial Load**  
   When a user opens the page, the bottom composer containing the microphone button, text input box, and send button is hidden (`<footer id="composer" hidden>`). An older or low-literacy user expecting to talk or type has no input box or microphone in sight. They must discover and click the large blue button ("Ayúdame con este formulario" / "Help me with this form") before any conversational controls appear.

2. **Sideways-Scrolling Sample Bar Offers No Scroll Affordance or Visual Clues**  
   The sample bar at the top houses 14 forms in an `overflow-x: auto` container with hidden scrollbars and no next/previous arrows. On a desktop or laptop without touch swiping, a senior user will only see the first 3 to 4 items and will likely assume those are the only available forms, never discovering the web forms or immigration forms further to the right.

3. **Inconsistent, Cryptic Sample Names and a Non-Form Slide Deck**  
   Several buttons use unformatted developer filenames with typos: `"HackthonInstructions"`, `"fw2_spanish"`, and `"i-485_es"`. Clicking `"HackthonInstructions"` displays a 74-slide hackathon presentation with zero form fields. An older user clicking this will be completely baffled because it is not a fillable form. Additionally, `"W-2 (Spanish)"` and `"fw2_spanish"` are duplicate buttons that open the exact same file.

4. **Equalizer/Sliders Icon for Settings and Lack of a Real "Restart" Button**  
   - The settings toggle uses a 3-bar slider/equalizer icon (`M4 6h8...`) rather than a standard, universally recognized gear icon.  
   - There is no button anywhere in the UI to restart or start over from scratch if the user makes a mistake. The circular arrow icon is labelled `"Repeat"`, which only asks the AI to repeat its previous question (`state.agent.repeat()`), rather than restarting the form.

5. **Technical Jargon in Settings and Developer Error Messages**  
   When opening Settings, the local model dropdown is empty, followed by a command-line instruction: *"Can't reach LM Studio. Start its server (lms server start) and open Settings again."* Other options include technical jargon such as *"Turn off model 'thinking' (much faster)"*. A low-literacy older person will not know what LM Studio, command-line terminal commands (`lms server start`), or model thinking mean.

## Anything Could Not Be Tested and Why

1. **Live AI Model Interactions (Items 6–9 in `docs/BROWSER-QA.md`)**:  
   - As directed in `docs/qa/PILOT-TASK.md`, LM Studio was deliberately offline for this pilot pass. Form filling, conversational turn-taking, prompt replies, and sensitive field masking with a running model were therefore out of scope.
2. **Microphone Audio Input & Voice Recognition**:  
   - The test was executed via Puppeteer headless browser automation without a physical audio input device or microphone permission grant. Speech-to-text accuracy and audio interruption detection were not testable via synthetic UI clicks alone.
3. **Speech Synthesis / Audio Playback**:  
   - Audio output could not be listened to audibly for pronunciation, volume, or pacing in the headless environment.
4. **Typing Real Personal Data**:  
   - In accordance with the prompt ("Do not type real personal data") and project privacy rules, no real identity or financial data was entered.
